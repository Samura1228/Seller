# Limassol Seller — этап 1

Отправляешь боту zip с фото. Дальше он сам:

1. Распознаёт каждую вещь (Claude vision): что это, бренд и модель, состояние, комплект, количество.
2. Подбирает цену: новая цена из веба, аналоги с Bazaraki через Apify, поправка на состояние. Предлагает цену и минимум.
3. Пишет мастер-тексты на RU и EN.
4. Присылает карточки на подтверждение по одной. Из карточки можно поправить количество, факты, цену и текст.

## Структура архива

```
вещи.zip
└── вещи/                  ← одна обёртка-папка допустима
    ├── sony наушники/     ← одна подпапка = одна вещь, имя = подсказка
    │   ├── 1.jpg
    │   └── 2.heic
    └── кресло/
        └── 1.jpg
```

- Поддерживаются HEIC (iPhone), JPG, PNG и WebP.
- Видео пропускаются.
- Фото, лежащие в корне архива без папки, тоже пропускаются.
- Вложенные папки внутри папки вещи относятся к той же вещи.
- Если отправить архив повторно, уже загруженные вещи пропускаются: дубликаты определяются по хэшу фото.
- EXIF удаляется полностью, включая GPS-координаты. Поворот фото при этом сохраняется.

## Карточка подтверждения

| Кнопка | Что делает |
|---|---|
| ✅ Утвердить | Цена и тексты утверждены, вещь получает статус `ready` |
| 🔢 Кол-во | Кнопки 1–6 или «другое число» |
| ✏️ Поправить факты | Пишешь, например: «это XM5, царапина на чашке». Распознавание, цена и тексты пересчитываются |
| 💶 Цена | Отправляешь `120` или `120/100` (цена / минимум) |
| 🔄 Пересчитать цену | Заново ищет цену и аналоги |
| 📝 Правка текста | Пишешь, например: «короче», «добавь, что работает с iPhone». Правка применяется к RU и EN |
| 🔄 Новый текст | Пишет текст с нуля |
| ⏭ Позже | Карточка уходит в конец очереди |
| 🗑 Не продаю | Статус `withdrawn` |

Цена, количество, «Лимасол, без доставки» и контакт продающего аккаунта не входят в AI-текст. Это фиксированный футер, он добавляется автоматически. Поэтому смена цены не требует переписывать текст.

Команды бота:
- `/next` — следующая карточка
- `/items` — список вещей
- `/item 12` — открыть вещь; готовую вещь можно вернуть на правку
- `/retry 12` — повторить обработку после ошибки
- `/cost` — расходы на AI
- `/cancel` — отменить ввод

## Деплой на Railway

1. Залей код в GitHub-репозиторий. В Railway создай **New Project → Deploy from GitHub repo**.
2. Добавь в проект **PostgreSQL**. В сервисе бота заведи переменную `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`.
3. Volume: правый клик по пустому месту на холсте проекта (или `⌘K` → «Volume») → выбрать сервис **Seller** → mount path `/data`.
4. Заполни переменные окружения по `.env.example`. `DATA_DIR` не задавай: по умолчанию используется `/data`.
5. Задеплой. Миграции БД применяются автоматически при старте. В логах должно появиться `Bot started as @...`.
6. Напиши боту `/start`.

Запускай ровно один инстанс: сессия Telegram не должна работать дважды одновременно. Это уже прописано в `railway.toml`.

## Локальный запуск

```bash
docker run -d --name seller-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=seller -p 5432:5432 postgres:16
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env        # заполни ключи
alembic upgrade head
python -m app.main
```

Не запускай бота локально и на Railway одновременно с одним `BOT_TOKEN`.

## Тесты

```bash
pytest                      # юнит-тесты, без БД
TEST_DATABASE_URL=postgresql://postgres:postgres@localhost:5432/seller_test pytest   # + сквозной тест (БД будет очищена!)
```

AI и Apify в тестах замоканы. Реальные вызовы делает только запущенный бот.

## Сколько стоит

Грубая оценка — примерно $0.15–0.25 за вещь, то есть около $10 на 50 вещей. Состав:
- Claude Sonnet 5.5 (распознавание по 8 фото, исследование цены, тексты);
- web search ($10 за 1000 поисков, до 5 поисков на вещь);
- Apify (~30 объявлений × ~$0.002).

Фактические траты по Claude показывает `/cost`. Apify считается в его кабинете.

## Этап 2: публикация в чаты

### 1. Сессия аккаунта для продаж
Сессию генерируешь один раз у себя на компьютере (на Railway вводить код некуда):

```bash
pip install telethon
python scripts/make_session.py
```

Скрипт попросит `TG_API_ID`, `TG_API_HASH`, номер **аккаунта для продаж**, код из Telegram и пароль 2FA. Пароль никуда не сохраняется.
Скопируй напечатанную строку в Railway → Variables → `USERBOT_SESSION`. После передеплоя в логах появится `Userbot started as @...`.

- Строка сессии = доступ к аккаунту. Не пересылай её никому.
- Не запускай с этой строкой ничего другого, пока бот работает: Telegram отзовёт сессию.
- При передеплое старый и новый инстансы не работают одновременно: новый ждёт, пока старый освободит блокировку в Postgres.

### 2. Чаты
1. Вступи в чаты с аккаунта для продаж **вручную**.
2. Отправь боту `/addchat @kipr6 @cyprus_market @sellbuycy`.
3. Бот проверит каждый чат:
   - можно ли туда писать (канал, бан, slow mode, запрет фото);
   - определит язык по последним сообщениям;
   - прочитает правила из описания и закрепов (AI).
4. Карточки чатов приходят по одной. Кнопки:
   - ✅ **Подтвердить и публиковать** — чат включается;
   - ✏️ **Поправить правила** — пишешь, например, «можно 2 поста в день»;
   - 🌐 **Язык** — переключает RU / EN / смешанный (в смешанных чатах посты на русском);
   - 🔄 **Перепроверить** — например, после того как вступил в чат;
   - 🚫 **Не публиковать сюда**.

Если в правилах лимит не указан, бот публикует **1 пост в сутки** на чат.

#### Все барахолки разом: `/scanchats`
**Из папки Telegram:** `/scanchats Лимассол` — берутся только чаты из папки «Лимассол» аккаунта для продаж. Все отмечены сразу. Те, в которых AI сомневается, что это барахолка, помечены 🤔. Если папка не найдена, бот покажет список папок.

**Без папки:** `/scanchats` — по всем группам аккаунта.
Бот просматривает группы и каналы, где состоит аккаунт для продаж. AI отмечает барахолки галочками, остальные группы показаны без галочек.
1. Сними или поставь галочки, нажми «➕ Добавить выбранные». Чаты добавляются по одному с паузой.
2. Каналы (📢), где писать могут только админы, бот заменяет их чатом-обсуждением, если он есть.
3. В итоге: ✅ — правила понятны, ❓ — нужна твоя проверка. Кнопка «Включить все с понятными правилами» включает ✅-чаты одним нажатием. ❓-чаты приходят карточками по одной.

#### Чаты с темами (форумы)
Бот читает список тем и сам выбирает тему для объявлений («Барахолка», «Продам», «Объявления» и т. п.). Правила он ищет в том числе в теме «Правила». Если выбрать не удалось, в карточке чата будет «🧵 Тема: ❓» — нажми «🧵 Тема для объявлений» и выбери вручную. Пока тема не выбрана, в такой чат ничего не публикуется.

`/recheckchats` перепроверяет все чаты, куда раньше нельзя было писать: например, форумы, добавленные до поддержки тем, или чаты, куда аккаунт вступил позже.

### 3. Версии постов
Когда чат включён и вещь утверждена, AI делает версию поста под каждый чат: язык, хэштеги, формат. Для разных чатов формулировки отличаются, чтобы не срабатывал антиспам, факты при этом те же. Цена, количество, «Лимасол» и контакт добавляются автоматически.

Карточка «Версии постов для чатов» показывает каждый пост ровно так, как он уйдёт. Кнопки: ✅ одобрить все · 🔄 переписать · 🗑 не публиковать (`/versions N` — сделать заново).

### 4. Публикация
По умолчанию публикации **выключены**. Включаются в `/publisher`. Там же:
- статус и очередь;
- кнопка «📤 Опубликовать следующий сейчас» — для проверки; не нарушает лимиты чатов.

Антибан-правила:
- окно 9:00–21:00 по Кипру;
- до 3 постов в час и 15 в сутки на все чаты;
- случайная пауза 12–35 минут между постами;
- лимиты и интервалы каждого чата, slow mode;
- одна и та же вещь не идёт два поста подряд;
- FloodWait → пауза, сколько попросил Telegram; PeerFlood (спам-ограничение) → пауза 24 часа и уведомление.

Если чат запретил писать, бот выключает его и сообщает тебе. Кто первый в очереди: вещи с ручным приоритетом, затем вещи без откликов, затем более дорогие.

Фото уходят альбомом с текстом в подписи. Если текст длиннее 1024 символов, он отправляется отдельным сообщением в ответ на альбом. Каждая вещь публикуется в каждый чат **один раз**. Еженедельные повторы — этап 6.

### 5. Где висят объявления и не удалили ли их
- `/posts` — сводка по вещам: ✅ висит · ⏳ в очереди · 📝 ждёт одобрения версий · 🗑 удалили в чате · ⚠️ не отправился.
- `/posts 12` — то же по одной вещи, со ссылками на посты.
- Каждые 2 часа бот проверяет, на месте ли опубликованные посты (`POST_CHECK_INTERVAL_MINUTES`). `/checkposts` — проверить сразу.
- Если пост удалили, приходит уведомление:
  - **возможная причина** — сообщения после нашего поста, которые на него отвечают или упоминают аккаунт для продаж (модератор, антиспам-бот);
  - **текущие ограничения Telegram** в этом чате;
  - кнопки: 🔁 опубликовать снова (в рамках лимитов чата) · ⏸ не публиковать в этот чат · 👌 понятно.
- Если в одном чате за 30 дней удалили 2 и больше постов, бот советует выключить этот чат.
- Удалённый пост продолжает считаться в суточном лимите чата.
- Если аккаунт исключили из чата, бот выключает этот чат и сообщает тебе.

## Этап 3: отклики и продажи

### Как бот находит отклики
Бот следит за аккаунтом для продаж:
- **Личные сообщения.** Бот ждёт ~20 секунд, чтобы собрать «Здравствуйте» и сам вопрос в одно уведомление. Затем AI определяет вещь по тексту, пересланному посту или контексту переписки.
- **Ответы на наши посты в чатах.** Вещь известна точно, AI не нужен.

Уведомление приходит в бот: вещь, покупатель, текст, суть, цена и **минимум**, ссылки «✉️ Открыть чат» и «💬 К ответу в чате». Отвечаешь покупателю **сам** с аккаунта для продаж. Бот сообщения не читает и не помечает прочитанными.

- **Вещь не понятна** («Привет, актуально?»): придёт карточка с кнопками вещей, выбери нужную. Если покупатель уточнит в следующих сообщениях, бот сам привяжет вещь и пришлёт обновлённую карточку.
- **Продолжение разговора** про ту же вещь не дублируется: ты уже в чате с этим человеком.
- **Спам, крипта, реклама и служебные сообщения Telegram** игнорируются.
- **После перезапуска** бот просматривает непрочитанные личные чаты, чтобы не потерять сообщения, пришедшие во время простоя.

### Кнопки
| Кнопка | Что происходит |
|---|---|
| 🔒 Бронь | Вещь в статусе «бронь», новые посты по ней не публикуются |
| 🔓 Снять бронь | Вещь возвращается в продажу |
| 💰 Продано | «За €70» или «Другая цена». Если штук несколько, продаётся одна, количество в постах обновляется. Последняя штука → статус «продано», **посты удаляются во всех чатах**, неопубликованные версии отменяются |
| 🔁 Это другая вещь | Переназначить отклик |
| 🗑 Снять с продажи | В `/item N`: вещь снята, посты удалены |

`/inquiries` — последние отклики. `/item N` — карточка вещи с кнопками брони и продажи.
