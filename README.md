# Limassol Seller — этап 1

Отправляешь боту zip с фото. Дальше он сам:

1. Распознаёт каждую вещь (Claude vision): что это, бренд и модель, состояние, комплект, количество.
2. Подбирает цену: новая цена из веба, аналоги с Bazaraki через Apify, поправка на состояние. Предлагает цену и минимум.
3. Пишет мастер-тексты на RU и EN.
4. Присылает карточки на подтверждение по одной. Из карточки можно поправить количество, факты, цену и текст.

## Структура архива

```
вещи.zip
└── вещи/                  ← одна обёртка-папка допустима
    ├── sony наушники/     ← одна подпапка = одна вещь, имя = подсказка
    │   ├── 1.jpg
    │   └── 2.heic
    └── кресло/
        └── 1.jpg
```

- Поддерживаются HEIC (iPhone), JPG, PNG и WebP.
- Видео пропускаются.
- Фото, лежащие в корне архива без папки, тоже пропускаются.
- Вложенные папки внутри папки вещи относятся к той же вещи.
- Если отправить архив повторно, уже загруженные вещи пропускаются: дубликаты определяются по хэшу фото.
- EXIF удаляется полностью, включая GPS-координаты. Поворот фото при этом сохраняется.

## Карточка подтверждения

| Кнопка | Что делает |
|---|---|
| ✅ Утвердить | Цена и тексты утверждены, вещь получает статус `ready` |
| 🔢 Кол-во | Кнопки 1–6 или «другое число» |
| ✏️ Поправить факты | Пишешь, например: «это XM5, царапина на чашке». Распознавание, цена и тексты пересчитываются |
| 💶 Цена | Отправляешь `120` или `120/100` (цена / минимум) |
| 🔄 Пересчитать цену | Заново ищет цену и аналоги |
| 📝 Правка текста | Пишешь, например: «короче», «добавь, что работает с iPhone». Правка применяется к RU и EN |
| 🔄 Новый текст | Пишет текст с нуля |
| ⏭ Позже | Карточка уходит в конец очереди |
| 🗑 Не продаю | Статус `withdrawn` |

Цена, количество, «Лимасол, без доставки» и контакт продающего аккаунта не входят в AI-текст. Это фиксированный футер, он добавляется автоматически. Поэтому смена цены не требует переписывать текст.

Команды бота:
- `/next` — следующая карточка
- `/items` — список вещей
- `/item 12` — открыть вещь; готовую вещь можно вернуть на правку
- `/retry 12` — повторить обработку после ошибки
- `/cost` — расходы на AI
- `/cancel` — отменить ввод

## Деплой на Railway

1. Залей код в GitHub-репозиторий. В Railway создай **New Project → Deploy from GitHub repo**.
2. Добавь в проект **PostgreSQL**. В сервисе бота заведи переменную `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`.
3. В сервисе бота: **Settings → Volumes → Add Volume**, mount path `/data`.
4. Заполни переменные окружения по `.env.example`. `DATA_DIR` не задавай: по умолчанию используется `/data`.
5. Задеплой. Миграции БД применяются автоматически при старте. В логах должно появиться `Bot started as @...`.
6. Напиши боту `/start`.

Запускай ровно один инстанс: сессия Telegram не должна работать дважды одновременно. Это уже прописано в `railway.toml`.

## Локальный запуск

```bash
docker run -d --name seller-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=seller -p 5432:5432 postgres:16
python3.12 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env        # заполни ключи
alembic upgrade head
python -m app.main
```

Не запускай бота локально и на Railway одновременно с одним `BOT_TOKEN`.

## Тесты

```bash
pytest                      # юнит-тесты, без БД
TEST_DATABASE_URL=postgresql://postgres:postgres@localhost:5432/seller_test pytest   # + сквозной тест (БД будет очищена!)
```

AI и Apify в тестах замоканы. Реальные вызовы делает только запущенный бот.

## Сколько стоит

Грубая оценка — примерно $0.15–0.25 за вещь, то есть около $10 на 50 вещей. Состав:
- Claude Sonnet 5.5 (распознавание по 8 фото, исследование цены, тексты);
- web search ($10 за 1000 поисков, до 5 поисков на вещь);
- Apify (~30 объявлений × ~$0.002).

Фактические траты по Claude показывает `/cost`. Apify считается в его кабинете.
