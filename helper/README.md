# Помощник для площадок (Mac)

Заполняет объявления на Bazaraki, Kyma.cy и Facebook Marketplace в настоящем браузере, со входом в твои аккаунты.
Скриншот заполненной формы приходит в бот, кнопку «Опубликовать» помощник нажимает только после твоего «✅».
Когда вещь продана, он сам снимает объявления.

Почему на Mac: Bazaraki блокирует серверы (Railway), а домашний интернет — нет. Пароли и сессии
хранятся только в профиле браузера на этом Mac (`~/.limassol-helper/chrome-profile`), на сервер не уходят.

## Установка (один раз)

1. Нужны Python 3.11+ и Google Chrome.
2. В Терминале, в папке `helper`:
   ```bash
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```
3. Настройки — файл `~/.limassol-helper/config.env`:
   ```
   SERVER_URL=https://<адрес сервиса на Railway>
   HELPER_TOKEN=<то же значение, что HELPER_TOKEN в Variables на Railway>
   PLATFORMS=bazaraki,kyma,facebook
   ```
4. Войди в каждую площадку (откроется окно Chrome; войди и закрой окно):
   ```bash
   .venv/bin/python helper.py login bazaraki
   .venv/bin/python helper.py login kyma
   .venv/bin/python helper.py login facebook
   ```
5. Проверь связь: `.venv/bin/python helper.py check`. В боте `/platforms` покажет «🟢 помощник на связи».
6. Запуск: `.venv/bin/python helper.py run` — или автозапуск при входе в Mac: `bash install_autostart.sh`.

## Как это работает

- Сервер выдаёт задания по одному: до 5 объявлений в сутки на площадку, пауза 30–90 минут, только 9:00–21:00.
- Форму помощник заполняет пошагово: отправляет на сервер список полей страницы, AI решает, что куда вписать
  и что нажать. Поэтому нет жёстко прописанных полей, и изменение вёрстки площадки помощника не ломает.
- Кнопку финальной публикации помощник не нажмёт без твоего «✅». Платные опции (VIP, TOP) он не выбирает.
- Если 45 минут нет ответа, форма закрывается, и помощник заполнит её снова позже.
- Если площадка просит войти заново, капчу или SMS-код, бот пришлёт «⚠️». Войди через `helper.py login …`
  и нажми «🔁 Попробовать снова».

Окно Chrome помощника лучше не трогать, пока он работает. Mac должен быть включён и не спать
(Системные настройки → Энергосбережение → «Не переходить в режим сна»).
